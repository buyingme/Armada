## Methodology

Rules-derived requirements are extracted directly from the official source
material:

- **Learn to Play (LTP):** `Resources/SWM01-ARMADA-LEARN-TO-PLAY/`
- **Rules Reference Guide (RRG) v1.5.0:** `Resources/SWM-RULES-REFERENCE-GUIDE-150/`

Each requirement includes a rules citation for traceability.

Where official rules do not determine a player-facing interaction or
architecture boundary, an accepted gameplay-interaction requirement may
instead identify its explicit Project Owner decision and applicable accepted
architecture authority.
